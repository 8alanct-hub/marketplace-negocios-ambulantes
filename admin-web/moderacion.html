Moderación

Fotos, productos y descripciones que los clientes marcaron como inapropiados. Los más recientes van primero.

Mantener: el contenido sigue publicado y el caso pasa a «Mantenidos».
Quitar: el contenido deja de verse en la app y el dueño del negocio recibe un aviso con el motivo para corregirlo.
Enviar a Reportes: cuando el problema es el negocio y no solo el contenido (su servicio, o vuelve a subir lo que se le quitó). Allí se decide si se suspende.
