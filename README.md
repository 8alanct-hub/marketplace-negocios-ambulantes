# Marketplace para Negocios Independientes

Marketplace móvil para pequeños negocios y emprendimientos independientes, diseñado para facilitar la conexión entre comercios locales y clientes.

La aplicación permite a los negocios crear su presencia dentro de la plataforma, publicar sus productos o servicios y gestionar pedidos, mientras que los clientes pueden descubrir diferentes comercios, explorar sus catálogos y realizar pedidos de forma sencilla.

## Objetivo

El proyecto busca brindar una herramienta accesible para que pequeños negocios y emprendimientos independientes puedan aumentar su presencia digital y conectar con nuevos clientes sin depender de grandes
